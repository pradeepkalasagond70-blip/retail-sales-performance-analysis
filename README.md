# Retail Sales Performance Analysis

An end-to-end retail sales analytics project focused on understanding sales performance, profitability, discount impact, product performance, and regional trends using Python and Tableau.

## Project Overview

This project analyzes retail transaction data to identify key business trends and performance drivers.

The analysis focuses on:

- Overall sales and profit performance
- Product-level sales and profitability
- Discount-related losses
- Category performance
- Regional sales performance
- Top-performing products
- Sales trends and business patterns
- Data quality and exploratory analysis

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Tableau Public
- Jupyter Notebook

## Analysis Performed

### 1. Data Analysis & Preparation
- Explored the dataset structure and key variables
- Performed data cleaning and transformation
- Investigated sales, profit, and discount-related metrics
- Identified patterns and potential data issues

### 2. Sales Analysis
- Analyzed total sales performance
- Compared sales across product categories
- Evaluated regional sales contribution
- Identified top-performing products

### 3. Profitability Analysis
- Analyzed total profit
- Calculated profit margin
- Identified products contributing strongly to profit
- Examined the impact of discounts on profitability

### 4. Product Analysis
- Identified top products by sales
- Identified top products by profit
- Identified products with significant discount-related losses

## Tableau Dashboard

## Key Business Questions

This project answers questions such as:

- Which product categories generate the highest sales?
- Which regions contribute most to overall sales?
- Which products are the strongest performers?
- Which products generate the highest profit?
- Which products are affected most by discount-related losses?
- How does discounting influence overall profitability?
